# Intent Build Node.js CLI Hello World Tool

## Goal
Create a small Node.js CLI tool in the repository root.

## Why
To provide a simple command-line interface for generating Markdown files from input values.

## Constraints
- The CLI entrypoint must be hello-world.cjs
- The output file must be hello-world.md
- No third-party runtime or framework is allowed

## Outcome
A working Node.js CLI tool that creates a Markdown file with the supplied input value.
